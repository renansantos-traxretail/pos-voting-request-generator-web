POS Voting Request Generator

Turn a spreadsheet of probe IDs into clearly separated request batches.

File handling: your spreadsheet is processed in this browser. The app does not upload it or send requests to the POS voting API.

1. Choose probes and request settings

Supported: .xlsx, .xlsm, .xls, and .csv. The first row is treated as column headers.

Request fields

0 means all valid unique IDs.

The batch limit is locked at 250.

Each field becomes an array. Enter comma-separated values, for example: front, shelf.

2. Preview and export

Choose a spreadsheet to get started.
